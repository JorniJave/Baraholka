## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/JorniJave/Baraholka.git
cd Baraholka/bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `bot/.env` в папке `bot/`:

```env
# Токен бота от @BotFather
BOT_TOKEN=your_bot_token_here

# ID администраторов (через запятую, без пробелов)
ADMIN_IDS=123456789,987654321

# ID канала для публикации объявлений (начинается с -100)
CHANNEL_ID=-1001234567890
```

**Как получить значения:**

- **BOT_TOKEN**: 
  1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
  2. Отправьте `/newbot` и следуйте инструкциям
  3. Скопируйте полученный токен

- **ADMIN_IDS**: 
  - ID можно узнать через команду `/myid` в боте (после запуска)
  - Или используйте [@userinfobot](https://t.me/userinfobot)
  - Несколько админов указывайте через запятую: `123456789,987654321`

- **CHANNEL_ID**: 
  1. Добавьте бота в канал как администратора
  2. Перешлите любое сообщение из канала в [@userinfobot](https://t.me/userinfobot)
  3. Скопируйте ID канала (начинается с `-100`)

### 4. Запуск бота

**Windows (PowerShell):**
```powershell
cd bot
python bot.py
```

**Linux/Mac:**
```bash
cd bot
python3 bot.py
```

**⚠️ ВАЖНО:** Убедитесь, что не запущено других экземпляров бота!

Если видите ошибку `TelegramConflictError`, используйте скрипт для остановки:
```powershell
.\stop_bot.ps1
```

| **User**      | 60 мин  | 0          | Стандартный пользователь      |

| **PREMIUM**    | 30 мин  | 120        | Уникальная приписка           |

**Автоматическая выдача VIP:**
- ✅ За 50 опубликованных постов
- ✅ За 20 приглашенных рефералов

**Уникальная приписка** - специальная отметка в объявлении, показывающая статус пользователя.

Пользователи могут создавать тикеты по следующим темам:

- 📢 **Купить рекламу** - запрос на размещение рекламы
- 📞 **Другое** - другие вопросы и предложения

**Приоритеты тикетов:**
- 🔴 **Высокий** - VIP и выше
- 🟡 **Средний** - обычные пользователи
- 🟢 **Низкий** - забаненные пользователи

**Возможности администраторов:**
- Просмотр всех тикетов с фильтрацией по приоритетам
- Ответы пользователям прямо в чате
- Закрытие и удаление тикетов
- Изменение приоритета тикета

## 🔗 Реферальная система

**Как работает:**
1. Пользователь получает уникальную реферальную ссылку через команду `/ref`
2. Друзья переходят по ссылке и регистрируются в боте
3. За каждого реферала пользователь получает бонусы
4. При достижении 20 рефералов автоматически выдается VIP привилегия

**Команды:**
- `/ref` - получить реферальную ссылку и статистику
- `/ref_top` - топ рефереров

## 🐛 Решение проблем

### Бот не запускается

**Проблема:** Ошибка при запуске

**Решения:**
1. Проверьте наличие файла `bot/.env` с правильными значениями
2. Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
3. Проверьте логи в файле `bot/baraholka.log`
4. Убедитесь, что Python версии 3.10 или выше

### Ошибка TelegramConflictError

**Проблема:** `Другой экземпляр бота уже запущен`

**Решение:**
```powershell
# Windows (PowerShell)
.\stop_bot.ps1

# Или вручную:
Get-Process python | Stop-Process -Force
```

### Ошибки с базой данных

**Проблема:** Ошибки при работе с БД

**Решения:**
1. Убедитесь, что у бота есть права на запись в директорию
2. При необходимости удалите `bot/baraholka.db` для пересоздания
3. Проверьте, что файл БД не открыт в другой программе

### Проблемы с публикацией в канал

**Проблема:** Бот не публикует объявления в канал

**Решения:**
1. Убедитесь, что бот добавлен в канал как **администратор**
2. Проверьте правильность `CHANNEL_ID` (должен начинаться с `-100`)
3. Убедитесь, что у бота есть права на публикацию постов в канале

### Не загружаются админы

**Проблема:** В логах видно только одного админа, хотя в `.env` указано несколько

**Решение:**
- Убедитесь, что админы указаны в одной строке через запятую: `ADMIN_IDS=123456789,987654321`
- Без пробелов после запятой
- Без кавычек вокруг значения

## 📦 Развертывание

### Локальное развертывание

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` с настройками
4. Запустите бота: `python bot.py`

### Развертывание на Linux сервере

#### 📋 Требования

- Linux сервер (Ubuntu/Debian/CentOS)
- Python 3.10 или выше
- Права суперпользователя (sudo)
- Git

#### 🚀 Пошаговая инструкция

**1. Подготовка сервера**

```bash
# Обновление системы (Ubuntu/Debian)
sudo apt update
sudo apt upgrade -y

# Установка Python и необходимых пакетов
sudo apt install -y python3 python3-pip python3-venv git

# Проверка версии Python (должна быть 3.10+)
python3 --version
```

**2. Создание пользователя для бота (рекомендуется)**

```bash
# Создать пользователя
sudo useradd -m -s /bin/bash baraholka

# Переключиться на пользователя
sudo su - baraholka
```

**3. Клонирование репозитория**

```bash
cd ~
git clone https://github.com/JorniJave/Baraholka.git
cd Baraholka/bot
```

**4. Настройка виртуального окружения**

```bash
# Создать виртуальное окружение
python3 -m venv venv

# Активировать виртуальное окружение
source venv/bin/activate

# Обновить pip
pip install --upgrade pip

# Установить зависимости
pip install -r requirements.txt
```

**5. Настройка переменных окружения**

```bash
# Создать файл .env
nano .env
```

Добавьте в файл:

```env
# Токен бота от @BotFather
BOT_TOKEN=your_bot_token_here

# ID администраторов (через запятую, без пробелов)
ADMIN_IDS=123456789,987654321

# ID канала для публикации объявлений (начинается с -100)
CHANNEL_ID=-1001234567890
```

Сохраните файл и установите права: `chmod 600 .env`

**6. Тестовый запуск**

```bash
source venv/bin/activate
python3 bot.py
```

Если бот запустился успешно, остановите его: `Ctrl+C`

**7. Настройка systemd для автозапуска**

Создайте файл сервиса:

```bash
sudo nano /etc/systemd/system/baraholka-bot.service
```

Добавьте содержимое (замените пути на ваши):

```ini
[Unit]
Description=Baraholka Telegram Bot
After=network.target

[Service]
Type=simple
User=baraholka
Group=baraholka
WorkingDirectory=/home/baraholka/Baraholka/bot
Environment="PATH=/home/baraholka/Baraholka/bot/venv/bin"
ExecStart=/home/baraholka/Baraholka/bot/venv/bin/python3 bot.py
Restart=always
RestartSec=10
StandardOutput=append:/home/baraholka/Baraholka/bot/baraholka.log
StandardError=append:/home/baraholka/Baraholka/bot/baraholka.log

[Install]
WantedBy=multi-user.target
```

Активируйте сервис:

```bash
# Перезагрузить systemd
sudo systemctl daemon-reload

# Включить автозапуск при загрузке системы
sudo systemctl enable baraholka-bot.service

# Запустить сервис
sudo systemctl start baraholka-bot.service

# Проверить статус
sudo systemctl status baraholka-bot.service
```

**8. Управление ботом**

```bash
# Просмотр статуса
sudo systemctl status baraholka-bot.service

# Остановка
sudo systemctl stop baraholka-bot.service

# Запуск
sudo systemctl start baraholka-bot.service

# Перезапуск
sudo systemctl restart baraholka-bot.service

# Просмотр логов
sudo journalctl -u baraholka-bot.service -f
```

**9. Обновление бота**

```bash
sudo systemctl stop baraholka-bot.service
cd ~/Baraholka
git pull origin main
cd bot
source venv/bin/activate
pip install -r requirements.txt
sudo systemctl start baraholka-bot.service
```

#### 🐛 Решение проблем

**Бот не запускается:**
- Проверьте логи: `sudo journalctl -u baraholka-bot.service -n 100`
- Проверьте файл `.env`: `cat /home/baraholka/Baraholka/bot/.env`
- Проверьте права доступа: `ls -la /home/baraholka/Baraholka/bot/`

**Ошибка "Permission denied":**
```bash
sudo chown -R baraholka:baraholka /home/baraholka/Baraholka
chmod 600 /home/baraholka/Baraholka/bot/.env
```

**Бот постоянно перезапускается:**
- Проверьте логи на ошибки: `sudo journalctl -u baraholka-bot.service -f`
- Убедитесь, что в `.env` указаны правильные значения
- Проверьте, не запущено ли несколько экземпляров: `ps aux | grep bot.py`
